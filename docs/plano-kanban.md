# Sugestão de cards para o GitHub Projects

Crie um Project com as colunas `A Fazer`, `Em Progresso` e `Concluído`. Cadastre os cards abaixo e mova-os conforme o trabalho for realizado.

| Tarefa | Coluna inicial sugerida |
|---|---|
| Criar repositório público | Concluído |
| Preparar estrutura de pastas | Concluído |
| Criar aplicação Flask | Concluído |
| Configurar banco SQLite | Concluído |
| Implementar cadastro de tarefas | Concluído |
| Implementar edição e exclusão | Concluído |
| Criar filtro por status | Concluído |
| Criar testes automatizados | Concluído |
| Configurar GitHub Actions | Concluído |
| Documentar diagramas UML | Concluído |
| Revisar README e instruções | A Fazer |
| Gravar vídeo de apresentação | A Fazer |

Ajuste as colunas para refletirem o que você realmente já fez. Não deixe tarefas como concluídas antes de verificar cada etapa.
