# Sugestões de mensagens de commit

O requisito da atividade pede pelo menos 10 commits. Faça os commits durante o desenvolvimento, em etapas reais. Não use esta lista para simular alterações que não foram feitas.

1. `chore: iniciar estrutura do projeto`
2. `feat: criar aplicação Flask`
3. `feat: configurar banco de dados SQLite`
4. `feat: adicionar cadastro de tarefas`
5. `feat: implementar listagem de tarefas`
6. `feat: permitir edição e exclusão de tarefas`
7. `feat: adicionar filtro por status`
8. `test: criar testes automatizados com pytest`
9. `ci: configurar execução de testes no GitHub Actions`
10. `docs: adicionar documentação e diagramas UML`
11. `feat: incluir prioridade nas tarefas`
12. `docs: registrar mudança de escopo`

Para criar um commit:

```bash
git add .
git commit -m "feat: adicionar cadastro de tarefas"
git push
```
